# Bubble Words — общая спека для всех 10 прототипов

Все 10 — отдельные **single-file** HTML-игры на одном словесном контенте. Механики РАЗНЫЕ.
Визуально — единый «подводный» стиль, чтобы категория смотрелась цельно.

## ЕДИНЫЙ ВИЗУАЛЬНЫЙ СТИЛЬ (обязательно во всех 10)
- Фон: подводный градиент сверху-вниз `linear-gradient(#1a6 f... )` → используй `background:linear-gradient(180deg,#1f6f9e 0%,#0b3a5c 60%,#06243a 100%)`, лёгкие пузырьки-кружки опц.
- «Пузырь-слово» = белая/полупрозрачная скруглённая капсула (border-radius большой), тёмный текст, мягкая тень. Цвет категории берём из `color`.
- Верхняя панель: слева заголовок игры, справа кнопка «↻» (рестарт). Прогресс/счёт по центру или слева.
- Шрифт: `-apple-system,Segoe UI,Roboto,Arial,sans-serif`, заглавные слова.
- Портрет-мобайл first: `max-width:430px`, центр по горизонтали, всё помещается без скролла на 430×900.

## ЖЁСТКИЕ ТРЕБОВАНИЯ (для каждого файла)
1. ОДИН файл .html, всё инлайн (CSS+JS). НИКАКИХ внешних сетей/CDN — работает офлайн.
2. Поддержка и тач, и мышь (pointer events).
3. Реальная играбельность: есть состояние победы и поражения, понятный фидбэк (тосты «Cool!», «Splendid!»), кнопка рестарта/новый уровень.
4. Без библиотек. Чистый vanilla JS.
5. Минимализм по [[feedback_prototype_minimalism]]: реализуй ИМЕННО заявленную механику, без лишних фич.
6. Не падать в консоль: код должен исполняться без ошибок при загрузке.
7. В шапке `<title>` — название игры.

## МЕХАНИКИ (по файлам)
- 01_impostor — найди лишнее: в каждой собранной кучке один чужак, тапни его. Таймер + штраф.
- 02_belt — конвейер: слова едут по ленте, флик в правильную корзину-категорию внизу до падения.
- 03_drop — словесный тетрис: слова-блоки падают в колонки, 3+ одной категории рядом → линия лопается.
- 04_constellations — соедини одной непрерывной линией все слова одной категории среди «звёзд».
- 05_defense — tower defense: слова-враги ползут по дорожке, ставь башни-категории, башня бьёт только свои слова.
- 06_merge — idle-merge: слова авто-спавнятся, мерджишь в группы, готовая категория = монеты, покупаешь генераторы.
- 07_crossword — судоку из слов: разложи плитки-слова в сетку так, чтобы каждый ряд был целой категорией.
- 08_duel — дуэль с ботом: общее поле, кто быстрее заберёт слова в свои категории; канат-перевес.
- 09_detective — угадай скрытое правило: кидаешь слова в коробку-гипотезу, игра отвечает да/нет, вычисли категорию за N проб.
- 10_climb — роглайт: карта узлов, в боях решаешь мини-сортировку, за победу реликвия-бустер, поднимаешься выше.
